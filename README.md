
# CPU Scheduling Simulator

A Python-based console application developed for PT 101 – Platform Technologies. It simulates CPU scheduling algorithms and compares their performance through Gantt charts and scheduling metrics.

## Scheduling Algorithms

- First Come, First Served (FCFS)
- Shortest Job First (SJF)
- Shortest Remaining Time First (SRTF)
- Round Robin (RR)

## Features

- Interactive console menu
- Manual process input and input validation
- Gantt chart visualization
- Completion, turnaround, waiting, and response time calculations
- Round Robin execution trace
- Algorithm performance comparison

## How to Run

1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder in Visual Studio Code.
4. Run the following command in the terminal:

```bash
python main.py
```

No additional Python packages are required.
